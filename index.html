Case Study: PromptMatrix 2.0 — Platform Rekayasa Prompt

🚨 The Business Challenge

Merancang prompt LLM yang andal pada banyak variabel rentan salah tanpa alat bantu terstruktur — tim perlu membandingkan varian, mengontrol format keluaran, dan menjaga API key tetap di tangan sendiri.

🧠 Engineering Approach & Solution

Saya membangun PromptMatrix v2 dengan TypeScript, Next.js, LangChain, dan Gemini API. Alat ini mendukung pengujian prompt multi-variabel, perbandingan output berdampingan, template yang dapat dipakai ulang, dan validasi format — berjalan sepenuhnya di sisi-klien.

📊 Verified Impact & Results

Arsitektur 100% sisi-klien Bring-Your-Own-Key (BYOK) — API key tidak pernah meninggalkan browser, menjamin nol kebocoran token dan kepatuhan ketat privasi data korporat.

Case Study: KantinKu ERP — Zero-Cost Cloud POS

🚨 The Business Challenge

Managing food & beverage canteen operations manually causes inaccurate COGS (HPP) calculations, untracked ingredient wastage, manual cashier shift reconciliation errors, and uncollected customer debt (kasbon). Commercial cloud ERP software incurs prohibitive monthly subscription costs for small-to-medium operators.

🧠 Engineering Approach & Solution

I engineered KantinKu ERP, a 100% serverless Cloud POS & Canteen ERP platform built on Google Apps Script and Google Sheets Database Engine. It automates Weighted Average Costing (WAC) ingredient valuation, BOM (Bill of Materials) recipe stock deduction upon sales, multi-role PIN authentication with brute-force protection, ScriptLock concurrency control to eliminate duplicate charges, customer kasbon tracking with WhatsApp notification dispatch, and thermal receipt printing.

📊 Verified Impact & Results

Eliminated 100% of recurring monthly database and cloud hosting subscription costs while delivering automated COGS recipe stock deduction and WhatsApp debt notifications.

Tech Stack & Architecture

Google Apps Script (GAS) JavaScript ES6 WAC Inventory Valuation BOM Recipe Stock Deduction CacheService & ScriptLock WhatsApp API Google Sheets DB Engine
