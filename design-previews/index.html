Five directions, all built from the real content.

SOC Console

Dark, amber phosphor, log lines. The site behaves like the monitoring console of a real SOC: boot logs, `$ whoami`, status readouts, green/amber status dots. Feels like the tool a SecOps engineer actually works in — not a decoration of one.

Field Manual

Cream paper, ink charcoal, rust accents, numbered sections. The portfolio is a printed technical manual — "MANUAL NO. SAI-2026", spec table, dotted-leader table of contents, six numbered sections (Offerings, Deployed Projects, Field Log 2002–2026, Field Reports, Certifications, Contact), and a tear-off resume request slip that posts to the real Formspree endpoint. The page carries recruiter's ink — checks, stars, initials, margin notes in a handwriting face (Caveat) — drawn as you scroll. Warm, tactile, and instantly human: a well-kept runbook read by hand.
